# Supremacia

Jogo escolar de estratégia territorial desenvolvido em Godot 4 e GDScript. A partida é local para dois jogadores no mesmo computador, com turnos alternados.

O protótipo atual inclui menu principal, distribuição inicial equilibrada, mapa reduzido, territórios selecionáveis, posicionamento de reforços e alternância de turnos. Combate e remanejamento serão adicionados nas próximas etapas.

## Executar

Importe `project.godot` no Godot 4 e pressione **F6** ou **F5**, ou execute `godot4 --path .` no terminal.
