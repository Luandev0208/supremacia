# Supremacia

Jogo escolar de estratégia territorial desenvolvido em Godot 4.7.2 e GDScript. A partida é local para dois jogadores no mesmo computador, com turnos alternados.

O jogo inclui menu principal, distribuição equilibrada de 42 territórios, mapa mundial interativo baseado no WAR, posicionamento inicial, bônus por seis continentes, alternância de turnos, ataques com dados, remanejamento entre territórios próprios conectados e condição de vitória. A primeira rodada é exclusiva para posicionamento, a segunda para ataques e, da terceira em diante, todas as fases ficam disponíveis.

## Executar

Importe `project.godot` no Godot 4 e pressione **F6** ou **F5**, ou execute `godot4 --path .` no terminal.
