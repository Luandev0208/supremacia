# Supremacia

Jogo escolar de estratégia territorial desenvolvido em Godot 4 e GDScript. A partida é local para dois jogadores no mesmo computador, com turnos alternados.

O protótipo atual inclui menu principal, distribuição inicial equilibrada, mapa reduzido e territórios selecionáveis. Combate e remanejamento serão adicionados nas próximas etapas.

## Executar

Importe `project.godot` no Godot 4 e pressione **F6** ou **F5**, ou execute `godot4 --path .` no terminal.

## Testes

Execute `godot4 --headless --path . --script res://tests/test_runner.gd`. O processo termina com código 0 quando todos os testes passam.
