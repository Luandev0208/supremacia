# Supremacia

**Supremacia** é um jogo de estratégia e conquista territorial em que dois jogadores disputam o controle de um mapa-múndi. Cada decisão importa: reforçar fronteiras, escolher o momento certo para atacar e proteger os territórios conquistados pode determinar o vencedor.

A partida é disputada por **dois jogadores no mesmo computador**, que se alternam a cada turno. O desafio é simples de entender, mas exige planejamento, estratégia e um pouco de sorte.

## Objetivo

O objetivo é **conquistar todos os territórios do adversário** e alcançar o domínio total do mapa.

Para isso, os jogadores precisam administrar seus exércitos, expandir seus territórios e aproveitar as vantagens de controlar continentes inteiros.

## O mapa

O mundo de Supremacia é dividido em **42 territórios**, distribuídos por seis continentes:

- América do Norte
- América do Sul
- Europa
- África
- Ásia
- Oceania

No início de cada partida, os territórios são distribuídos aleatoriamente de forma equilibrada: cada jogador recebe **21 territórios**, inicialmente ocupados por um exército.

Os territórios pertencentes a cada jogador são identificados por cores, e o mapa mostra a quantidade de tropas posicionadas em cada região.

## Como funciona uma partida

Supremacia é jogado em turnos, com fases que organizam as ações dos jogadores.

### Primeira rodada: posicionamento

Cada jogador escolhe onde distribuir seus exércitos adicionais entre os territórios que controla.

É o momento de preparar as defesas, fortalecer fronteiras e planejar os primeiros ataques.

### Segunda rodada: ataques

Os jogadores começam a disputar o mapa, atacando territórios inimigos vizinhos.

Uma boa ofensiva pode abrir caminhos para novas conquistas, mas um ataque mal planejado pode enfraquecer a defesa dos próprios territórios.

### Da terceira rodada em diante

Cada turno é dividido em três etapas:

1. **Reforços:** receber e posicionar novos exércitos.
2. **Ataques:** enfrentar territórios inimigos e tentar conquistá-los.
3. **Remanejamento:** reorganizar tropas entre territórios próprios conectados.

Após passar para o remanejamento, não é possível voltar à fase de ataques naquele turno.

## Sistema de combate

As batalhas são resolvidas com dados.

- O atacante escolhe um território seu com pelo menos dois exércitos e um território inimigo vizinho.
- Cada lado lança até **três dados**, conforme a quantidade de exércitos disponíveis.
- Os resultados são organizados do maior para o menor e comparados entre si.
- Cada comparação provoca a perda de um exército de um dos lados.
- **Em caso de empate, a defesa leva vantagem.**
- O território de origem do ataque precisa manter pelo menos um exército.

Se o defensor perder todos os seus exércitos, o território é conquistado e passa para o atacante, que transfere tropas para ocupá-lo.

## Reforços e continentes

A cada nova fase de reforços, o jogador recebe tropas conforme a quantidade de territórios que controla, com um mínimo de **três novos exércitos**.

Controlar um continente inteiro também garante reforços adicionais:

| Continente | Bônus |
| --- | ---: |
| América do Norte | +5 exércitos |
| América do Sul | +2 exércitos |
| Europa | +5 exércitos |
| África | +3 exércitos |
| Ásia | +7 exércitos |
| Oceania | +2 exércitos |

Conquistar continentes é uma forma de fortalecer seu exército e aumentar suas possibilidades de expansão nas rodadas seguintes.

## Movimentação de tropas

Durante a fase de remanejamento, é possível transferir exércitos entre territórios próprios, desde que exista um caminho conectado por regiões controladas pelo mesmo jogador.

O jogador escolhe a origem, o destino e a quantidade de tropas a movimentar. Pelo menos um exército deve permanecer no território de origem.

Atualmente, cada jogador pode realizar **um remanejamento por turno**.

## Vitória

A partida termina quando um dos jogadores conquista todos os territórios do mapa.

Vence quem souber equilibrar **ataque, defesa, reforços e movimentação de tropas** até alcançar a supremacia.

---

**Supremacia** é um jogo de estratégia para dois jogadores locais, inspirado em jogos clássicos de conquista territorial. É um projeto escolar independente, sem afiliação com a marca WAR.
